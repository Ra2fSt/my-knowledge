## 结构与界面

- `/learn/` 独立学习地图；首页加入入口与七科快捷链接。
- 主干四色：数据结构蓝、计组橙、操作系统绿、网络紫。
- 旁支三色：数电玫红、编译青、汇编橄榄色。科目名称和代码同时可读，颜色不是唯一标识。
- 统一配置 `src/lib/subjects.ts`，页面和图谱共用。
- Markdown 新字段：section / kind / parent / order / coverage / relations；旧笔记可省略。
- parent 构成逻辑章节树，文件继续放在 `src/content/notes/` 顶层。
- coverage 是内容完整度；status 是个人掌握状态，两者分开。
- 关系强度 1/2/3 对应细/中/粗线。引用默认 1，parent 章节关系 3；显式关系含类型、理由、方向语义。
- 双向引用合并成一条边，取最大强度、保留两个方向的文字说明。不是根据出现次数猜重要程度。
- 显式关系进入出链/反链/相关推荐；无效结构目标和父级循环使构建报错。
- 图谱支持范围、单科、最小强度筛选、标题开关和视图重置；有无需操作画布的文字视图。单科筛选只看科内边，跨科联系请选择全部学科。
- 笔记页有章节路径、学习侧栏、手机折叠目录、同级阅读顺序、关系说明、适合小屏的表格滚动。
- Astro 图谱懒加载改为实际 IntersectionObserver + 动态 import，不再依赖无效的 client:visible。
