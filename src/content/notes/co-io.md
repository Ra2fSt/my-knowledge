## 三种方式对照

| 方式 | CPU 做什么               | 主要成本                      |
| ---- | ------------------------ | ----------------------------- |
| 查询 | 反复读状态，并按程序搬运 | 等待期间占用 CPU              |
| 中断 | 设备就绪后进入服务程序   | 响应、保存/恢复现场与搬运开销 |
| DMA  | 配置传输，完成后处理状态 | 初始化、总线竞争与完成处理    |

DMA 通常使批量数据直接在设备与内存间搬运，不能说 CPU 从头到尾完全不参与。中断是通知/控制机制，DMA 是搬运机制，二者可以一起使用。
