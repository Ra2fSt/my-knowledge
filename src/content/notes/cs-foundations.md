## 这张地图怎么读

把计算机基础看作一条连起来的链：**问题 → 数据结构与算法 → 程序 → 指令 → 电路**。操作系统管理程序使用的资源，计算机网络让多台机器协作。这里先建立复习骨架，再逐步把例题、推导和错题挂上去。

这是按常见本科课程组织的学习地图，**没有核验你报考年份的完整 408 官方大纲，不作为考纲原文或考频统计**。考点取舍以后用目标年份大纲、指定教材和真题逐项对照；「总览已建」也不代表你已经掌握。

## 本学期与专业旁支

- **数电优先并行**：[[digital-logic|数字逻辑 · 本学期旁支]] → [[co-arithmetic|数据表示与运算]] → [[co-cpu|CPU、控制与流水线]]。先理解门、组合电路、时序电路，再看 ALU 和控制器。
- **汇编打通软硬件**：[[assembly|汇编语言 · 专业旁支]] ↔ [[co-isa|指令系统与寻址]] ↔ [[co-memory|存储系统]]。把变量、分支、函数调用对应到寄存器和地址。
- **编译补上语言到机器的桥**：[[compiler|编译原理 · 专业旁支]] 连接 [[ds-trees|树与二叉树]]、[[ds-graphs|图与图算法]] 与 [[assembly|汇编语言 · 专业旁支]]。
- **前置补漏**：[[cs-prerequisites|C 语言与离散数学]] 收纳 C 语言、离散数学与必要数学工具，不额外开成一套大课。

## 建议学习路线

1. 补 C 的数组、指针、结构体、递归；同时复习二进制与逻辑运算。
2. 数据结构按「复杂度 → 线性结构 → 树图 → 查找排序」推进；计组按「系统 → 数值 → 存储 → 指令 → CPU → 总线与 I/O」推进。
3. 数电跟学期课程进度学，把门电路、寄存器、状态机接到计组；不必等学完数电才开始计组。
4. 有了存储、指令、中断基础后展开操作系统；网络可以独立穿插。
5. 每学完一章，留下：一张概念图、一个手算例题、一条跨科联系、一个错误反例。

## 三条值得反复走的跨科路径

- **一次数组遍历**：[[ds-linear|线性表]] → [[co-memory|存储系统]] → [[os-overview|操作系统 · 总览骨架]]。抽象访问次数相同，局部性仍会改变真实运行时间。
- **一次函数调用**：[[ds-stack-queue|栈、队列与数组]] → [[assembly|汇编语言 · 专业旁支]] → [[co-isa|指令系统与寻址]] → [[co-cpu|CPU、控制与流水线]]。算法递归最终落到栈帧、指令和硬件执行。
- **一条最短路径**：[[ds-graphs|图与图算法]] → [[net-overview|计算机网络 · 总览骨架]]。图算法为路由建模提供工具，但实际协议还有拓扑变化与收敛问题。
