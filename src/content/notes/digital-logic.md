## 本学期学习路线

逻辑代数 → 逻辑函数化简 → 组合逻辑 → 触发器与寄存器 → 时序逻辑 → 状态机与综合设计。具体实验平台和器件符号以本学期课程为准。

## 章节骨架

| 模块       | 学会什么                                   | 对接计组            |
| ---------- | ------------------------------------------ | ------------------- |
| 数制与逻辑 | 逻辑运算、真值表、布尔恒等式               | 位表示与按位运算    |
| 化简       | 最小项/最大项、卡诺图、无关项              | 减少组合电路复杂度  |
| 组合电路   | 编码器、译码器、多路选择器、加法器、比较器 | ALU、片选与数据通路 |
| 时序元件   | 锁存器、触发器、寄存器、建立/保持时间      | 保存 CPU 状态       |
| 时序系统   | 计数器、状态图、状态表、同步设计           | 控制器与微操作      |
| 实验与设计 | 设计→仿真→验证→记录                        | 解释真实硬件行为    |

## 跨科桥梁

[[co-arithmetic|数据表示与运算]] 的加法器由组合逻辑实现；[[co-cpu|CPU、控制与流水线]] 的控制器与寄存器构成时序系统；[[co-memory|存储系统]] 的芯片选择需要译码。组合电路当前输出由当前输入决定，时序电路还依赖内部状态。
