## 总对照（典型数组实现）

| 算法     | 平均时间     | 最坏时间     | 辅助空间                    | 稳定性                 |
| -------- | ------------ | ------------ | --------------------------- | ---------------------- |
| 直接插入 | O(n²)        | O(n²)        | O(1)                        | 稳定                   |
| 冒泡     | O(n²)        | O(n²)        | O(1)                        | 稳定                   |
| 简单选择 | O(n²)        | O(n²)        | O(1)                        | 不稳定                 |
| 希尔     | 依赖增量序列 | 依赖增量序列 | O(1)                        | 不稳定                 |
| 快速     | O(n log n)   | O(n²)        | 平均 O(log n)，最坏 O(n) 栈 | 不稳定                 |
| 堆       | O(n log n)   | O(n log n)   | O(1)                        | 不稳定                 |
| 二路归并 | O(n log n)   | O(n log n)   | O(n)                        | 稳定                   |
| LSD 基数 | O(d(n+r))    | O(d(n+r))    | O(n+r)                      | 每趟稳定分配收集时稳定 |

d 为关键字位数，r 为基数；基数排序不受基于比较的排序下界直接约束。归并保持稳定需要相等时先取左侧；插入/冒泡也要避免交换相等关键字。

## 外部排序的重点

数据超出内存后，I/O 次数成为重要成本。给定初始段数 r₀、每趟最多合并 k 段，理想均衡模型下趟数为 ceil(log_k r₀)，但缓冲区、最后一趟和输入输出统计方式均要看题设。
