## 核心问题

线性表描述元素间的一对一关系；顺序表与链表是它的存储实现。

## 考点清单

- [ ] 顺序表按下标访问、查找、插入、删除与扩容。
- [ ] 单链表、双链表、循环链表；头指针与头结点的区别。
- [ ] 带/不带头结点的首元素删除；空表与尾结点处理。
- [ ] 逆置、去重、有序合并、快慢指针等算法设计。

## 操作代价

| 操作             | 顺序表         | 单链表               |
| ---------------- | -------------- | -------------------- |
| 按序号访问       | O(1)           | O(n)                 |
| 按值查找，未排序 | O(n)           | O(n)                 |
| 已知合法插入位置 | 最坏 O(n) 移动 | 已知前驱时 O(1) 改链 |
| 删除指定位置     | 最坏 O(n) 移动 | 已知前驱时 O(1) 改链 |

## 易错点

先保存后继再断链；修改双链表时同时维护前后指针。声称链表插删 O(1) 时，必须说明定位成本是否已经支付。数组连续布局通常有利于 [[co-memory|存储系统]] 的局部性。
