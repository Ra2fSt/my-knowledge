## 选择与代价

| 结构       | 查找特点                      | 注意                 |
| ---------- | ----------------------------- | -------------------- |
| 有序数组   | 折半 O(log n)                 | 更新可能需 O(n) 移动 |
| 普通 BST   | 与树高有关                    | 退化时 O(n)          |
| 平衡搜索树 | 控制树高                      | 要付出维护平衡的代价 |
| 散列表     | 良好分布与受控装填下期望 O(1) | 最坏仍可能 O(n)      |
| B/B+ 树    | 多路分支降低树高              | 常用于块存储索引     |

## 易错点

折半区间开闭必须与 mid 更新一致。ASL 分成功与失败，按题目的概率分布加权；散列失败查找要按探测终止位置计数。开放定址删除通常需要删除标记，直接清空可能截断查找链。B 树的「阶」先按题设定义。
